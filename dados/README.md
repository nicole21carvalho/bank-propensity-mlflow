# Dados

**Bank Marketing**, do UCI Machine Learning Repository: campanhas de telemarketing de um banco português que
ofereceram um depósito a prazo (um investimento). Arquivo usado: `bank-additional-full.csv`, com 41.188 ligações
em ordem de data, de maio de 2008 a novembro de 2010, e 20 variáveis.

- Fonte: Moro, S., Rita, P. e Cortez, P. (2014). *Bank Marketing*. UCI Machine Learning Repository.
  [doi.org/10.24432/C5K306](https://doi.org/10.24432/C5K306)
- Licença: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- Download: <https://archive.ics.uci.edu/static/public/222/bank+marketing.zip>
- SHA-256 conferido antes de usar: `e0bf5f5de5b846e2f18e9d90606637267d46dfa260e0f17bb12e605db5efbeb4`

O arquivo não fica no repositório: `mira-explorar` e `mira-treinar` baixam na primeira vez e recusam um arquivo com
outro SHA-256 (outro conteúdo daria outros resultados). Os dados são anônimos: não há nome, documento nem contato
de nenhum cliente.
